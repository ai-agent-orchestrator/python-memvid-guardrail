# 골든셋 두 축 보고서 — 가짜 임베더 기준선

2026-11-06 · 합성 자료만 · 가짜 임베더(글자 n-gram 해싱)라서 **의미 검색 결과가 아닙니다.** 실제 E5 결과는 대표 PC에서 같은 명령으로 만듭니다.

```bash
python scripts/golden_two_axis.py --out docs/evidence/golden/fake_two_axis.json
HF_HUB_OFFLINE=1 python scripts/golden_two_axis.py --embedder e5 --revision <pinned> --out docs/evidence/golden/e5_two_axis.json
```

자료: 근거 질문 20개(`golden_set.json`)와 무근거 질문 9개(`golden_no_evidence.json`). 유형별로 3개마다 1개를 확인 세트에 넣어 비교 19개, 확인 10개로 나눕니다. 임계값은 비교 세트로만 정하고 확인 세트에는 한 번만 적용합니다.

## 두 축으로 나눠 보는 이유

| 축 | 질문 | 지표 |
| --- | --- | --- |
| 순위 | 정답 조문을 몇 위에서 찾았나? | 1위 정답, 3위 안 정답, MRR |
| 판정 | 게이트가 "근거 있음"으로 받아들였나? | 아래 6가지 결과 |

| 결과 | 뜻 | 볼 것 |
| --- | --- | --- |
| `found_accepted` | 정답이 1위이고 통과 | 정상 |
| `found_refused` | 정답이 1위인데 거절 | ① B02b의 Q22와 같은 경우. 임계값이 너무 엄격함 |
| `wrong_accepted` | 1위가 오답인데 통과 | **가장 위험.** 틀린 근거로 답이 생성됨 |
| `wrong_refused` | 1위가 오답이고 거절 | 안전하지만 검색이 약함 |
| `no_evidence_refused` | 무근거 질문을 거절 | 정상 |
| `no_evidence_accepted` | 무근거 질문을 통과 | 위험. 근거 없이 답이 생성됨 |

| 세트 | 1위 정답 | 3위 안 정답 | MRR | 정답·통과 | 정답인데 거절 | 오답·통과 | 오답·거절 | 무근거 거절 | 무근거 통과 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 비교 | 10/14 | 10/14 | 0.714 | 5 | 5 | 0 | 4 | 7 | 0 |
| 확인 | 2/6 | 3/6 | 0.417 | 0 | 2 | 0 | 4 | 2 | 0 |

읽는 법: 글자 기준선은 무근거 질문과 근거 질문의 점수가 많이 겹칩니다. "무근거 통과 0"을 지키려면 임계값을 높여야 하고, 그 대가로 정답을 찾고도 거절하는 경우가 많아집니다. 의미를 아는 임베딩이라면 두 점수 분포가 더 잘 갈라져 `found_refused`가 줄어야 합니다. E5로 이 표를 다시 만들어 비교하는 것이 학습 트랙 E6입니다.
